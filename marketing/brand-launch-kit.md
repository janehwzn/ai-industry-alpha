## First-week publishing plan

- **Monday — LinkedIn:** Launch post + one concrete source-linked signal.
- **Tuesday — X:** 3-post thread about one signal, including source and a falsifier.
- **Wednesday — Instagram:** 5-slide carousel: signal, evidence, why it may matter, caveat, question.
- **Thursday — X + LinkedIn:** A second signal with a founder-oriented question.
- **Friday — TikTok / Xiaohongshu:** Adapt one topic into a short video script and a native Chinese note.
- **Sunday — All channels:** Weekly Signal Ledger teaser linking to the complete brief.

## Before publishing

- Verify handle availability and use a consistent logo/avatar.
- Add a working link to the website on each profile.
- Set up account recovery and two-factor authentication.
- Connect accounts to Postiz or Metricool only after the owner has created them.
- Review every generated post for factual accuracy, source quality, and native platform tone.
- Do not auto-post generated content until the draft workflow has been reviewed for several cycles.
